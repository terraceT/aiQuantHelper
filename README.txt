================================================================================
  aiQuantHelper —— 币安合约账户的 AI 运维助手（Windows 版，只读）
================================================================================

项目概览
--------------------------------------------------------------------------------
一句话：用中文问 AI「我的仓位怎么样、有什么风险、这个报错怎么办」，AI 自己去查你的币安
账户和运维手册，然后给出有依据的回答。双击 start.bat 即可运行，不需要懂编程。

技术架构：AI Agent + MCP 工具协议 + DeepSeek 大模型 + RAG 运维手册检索

  浏览器页面（账户概览 + 「AI 运维助手」对话框）
      │  HTTP，只监听本机 127.0.0.1
      ▼
  Web 服务（Starlette / uvicorn）  app/web.py
      │
      ▼
  AI Agent  app/agent.py
      │  · 把问题交给 DeepSeek 大模型，模型自己决定调用哪些工具（Function Calling）
      │  · 执行工具、把结果交回模型，最多循环 8 轮，直到得出结论
      │  · 每次问答写审计日志（问题、调用了哪些工具、耗时、token；不记录密钥）
      ├──────────────►  DeepSeek 大模型（OpenAI 兼容接口，默认 deepseek-flash）
      │
      │  MCP 协议（Model Context Protocol，stdio 子进程）
      ▼
  MCP Server  app/mcp_server.py：9 个只读工具
      ├─ 账户数据工具（账户与持仓、挂单与条件单、资金流水、现货余额、风险体检、
      │  行情与资金费率、连通性与 API 权限、运维日报）
      │       │
      │       ▼
      │   数据层  app/datasource.py：两种来源、同一套处理
      │       ├─ LIVE：币安 REST API（HMAC 签名，只发 GET 请求）  app/binance.py
      │       └─ MOCK：mock/ 目录里的模拟数据（与币安接口返回格式完全相同）
      │
      └─ search_runbook：RAG 运维手册检索  app/runbook.py + docs/runbook.md
              · 手册按条目切块（R1~R20：错误码、API Key 配置、代理、风险概念……）
              · BM25 算法打分：中文按相邻两字切词、英文和数字按词切，
                所以「签名不对」「-2015」「强平价是什么」这类说法都能找到对应条目
              · 检出的条目交给大模型，回答时引用条目编号（如 R5）
              · 不依赖向量模型，零额外下载；手册改了自动重建索引，可自行追加条目

设计要点：
  · 只读安全：币安客户端只有 GET 请求，AI 没有任何下单 / 撤单 / 划转 / 提现工具（有自动测试钉住）
  · 不编造：系统提示词要求所有数字都来自工具返回；工具出错如实报告原因
  · 三态分明：页面每块数据独立查询，「加载中 / 出错（写明原因）/ 有数据」分开显示
  · 演示可用：不填币安 Key 也能完整体验（MOCK），页面和 AI 都会明确标注是演示数据
  · 一键运行：start.bat 自动准备 Python、虚拟环境和依赖，多个下载源自动切换

主要依赖：openai（调用 DeepSeek）、mcp（MCP 协议）、starlette + uvicorn（Web 服务）、requests

一、这是什么
--------------------------------------------------------------------------------
在浏览器里打开一个本地页面，可以看到你的币安 U 本位合约账户：
  · 权益、钱包余额、未实现盈亏、可用余额、实际杠杆、保证金率
  · 持仓（方向 / 数量 / 开仓价 / 标记价 / 盈亏 / 强平价 / 强平距离）
  · 挂单和止损止盈条件单、近 7 天资金流水（已实现盈亏 / 手续费 / 资金费）、现货余额
  · 风险体检（杠杆、强平距离、集中度、可用余额、有没有挂止损）

页面右下角有「🤖 AI 运维助手」按钮，点开就能用中文对话，例如：
  「今天的运维日报情况怎么样」「我的仓位是什么情况」「有什么风险需要注意」
  「检查一下币安连接和 API 权限」「-2015 报错是什么意思」
AI（DeepSeek 大模型）会自己去查你的账户数据和运维手册，然后回答。

⛔ 全程只读：本程序没有任何下单、撤单、改杠杆、划转、提现的功能，AI 也没有。

两种模式：
  · 演示模式（MOCK）：没填币安 API Key 时自动进入，显示 mock/ 目录里的模拟账户，
    页面顶部有黄色「MOCK 演示数据」标记。不需要币安账号也能完整体验。
  · 实盘模式（LIVE）：填了币安 API Key 后，只读查询你的真实账户，页面顶部是绿色「LIVE 实盘」。


二、环境要求
--------------------------------------------------------------------------------
  · Windows 10 / 11
  · 不需要自己装 Python：电脑上已有 Python 3.10+ 就直接用；没有的话，start.bat 会自动下载
    官方免安装版 Python 放进本目录的 .python 文件夹（不需要管理员权限，不修改系统设置，
    不影响电脑上其他程序；删掉 .python 文件夹即可彻底清除）。
  · 能上网（第一次运行要下载 Python 和依赖，约 1~5 分钟；会自动尝试官方源和国内镜像）
  · 一个 DeepSeek 大模型的 API Key（必需，见第四节，充值几元就够用很久）
  · 币安 API Key（可选，见第五节；不填就是演示模式）


三、快速开始（只需要运行一个脚本）
--------------------------------------------------------------------------------
  1. 下载并解压本工程（GitHub 页面 Code → Download ZIP，或 git clone）。
     建议放在路径里没有中文和空格的目录，例如 D:\aiQuantHelper 。
  2. 双击 start.bat 。
     第一次运行会全自动完成：准备 Python（没有就自动下载）→ 创建虚拟环境 .venv → 安装依赖
     → 生成配置文件 config.ini 。你什么都不用装、不用选。
  3. 因为还没有填 DeepSeek 的 key，程序会提示申请步骤并拒绝启动，同时用记事本打开 config.ini。
     按第四节拿到 key，粘贴到 [deepseek] 下面的 api_key = 后面，保存。
  4. 再次双击 start.bat 。看到「页面地址：http://127.0.0.1:8866/」后，浏览器会自动打开页面。
  5. 点页面右下角「🤖 AI 运维助手」开始对话。

  停止：关掉 start.bat 的黑色窗口（或在窗口里按 Ctrl + C）。
  以后每次使用：双击 start.bat 即可（依赖已装好，几秒就能启动）。


四、申请 DeepSeek 大模型 API Key（必需）
--------------------------------------------------------------------------------
  1. 浏览器打开 https://platform.deepseek.com ，用手机号或邮箱注册并登录。
  2. 左侧菜单「充值」(Top up)：充值少量余额（几元即可）。
     没有余额时 AI 助手会报 402 Insufficient Balance。
     参考：一次问答通常消耗几千到几万 token，费用一般不到 1 分钱。
  3. 左侧菜单「API keys」→「创建 API key」，名字随便填（如 aiQuantHelper）。
  4. 复制弹出的 key（以 sk- 开头）。⚠ 它只显示这一次，请立即复制保存。
  5. 用记事本打开本目录下的 config.ini，填到 [deepseek] 段：
         api_key = sk-你复制的key
     保存后重新运行 start.bat 。

  启动时程序会用这个 key 访问 DeepSeek 验证一次：
    · 没填       ⇒ 打印上面的申请步骤，不启动；
    · key 无效   ⇒ 提示「DeepSeek 拒绝了这个 API Key」，不启动；
    · 模型名不对 ⇒ 列出你可用的模型名，不启动。
  模型默认 deepseek-flash（快、便宜）；想要更强可改成 model = deepseek-v4-pro 。


  换用其他大模型（可选）
  ······························································
  程序通过「OpenAI 兼容接口」调用大模型，不只能用 DeepSeek。改 config.ini 的 [deepseek] 段
  三行即可（段名不用改）：
      base_url = 平台的 OpenAI 兼容接口地址
      model    = 平台上的模型名
      api_key  = 在该平台申请的 key

  ⚠ 硬性要求：模型必须支持「工具调用」(Function Calling / Tools)。AI 运维助手就是靠它去
     查账户、查手册的；不支持的模型要么报错，要么只会空谈、拿不到真实数据。

  常见平台的接口地址（2026-11 实测接口存在；模型名经常更新，请以平台文档为准）：
      平台                        base_url
      DeepSeek（默认）            https://api.deepseek.com
      阿里云百炼 · 通义千问        https://dashscope.aliyuncs.com/compatible-mode/v1
      月之暗面 · Kimi             https://api.moonshot.cn/v1
      智谱 · GLM                  https://open.bigmodel.cn/api/paas/v4
      硅基流动（多家开源模型）     https://api.siliconflow.cn/v1
      本机 Ollama（离线运行）      http://127.0.0.1:11434/v1   （api_key 随便填，如 ollama；未在本机实测）

  例：换成通义千问
      [deepseek]
      api_key = 你在阿里云百炼申请的 key
      model = （百炼文档里支持工具调用的模型名）
      base_url = https://dashscope.aliyuncs.com/compatible-mode/v1

  改完重新运行 start.bat。启动时会用新的 key 验证一次：key 被拒（401）会拒绝启动；
  模型名不在该平台的模型列表里只会警告（有的平台列表不全），照常启动。
  想换回 DeepSeek：把三行改回 config.example.ini 里的默认值即可。


五、（可选）接入你的真实币安账户
--------------------------------------------------------------------------------
  强烈建议单独创建一个「只读」API Key 给本程序用：
  1. 登录币安网页版 → 右上角头像 → API 管理 → 创建 API → 选「系统生成」。
  2. 完成安全验证后得到 API Key 和 Secret Key（Secret Key 只显示一次，立即复制）。
  3. 编辑权限：只勾选「允许读取」(Enable Reading)。
     ⛔ 不要勾选「允许现货及杠杆交易」「允许合约」「允许提现」—— 本程序用不到。
  4. 建议设置 IP 白名单（使用代理时填代理的出口 IP）。
  5. 填进 config.ini 的 [binance] 段，两个都要填：
         api_key = 你的 API Key
         api_secret = 你的 Secret Key
  6. 重新运行 start.bat 。启动窗口会显示「实盘模式（LIVE）」以及这个 Key 开了哪些权限；
     如果开了提现权限，会提醒你去关掉。

  规则：两个都不填 ⇒ 演示模式；两个都填 ⇒ 实盘模式；只填一个 ⇒ 程序拒绝启动并提示。
  想换回演示模式：把两个都清空，重新运行 start.bat 。


六、访问不了币安？配置代理
--------------------------------------------------------------------------------
  部分地区和网络直连不了币安（表现为超时或 HTTP 451）。在 config.ini 的 [binance] 填：
      proxy = http://127.0.0.1:7890          （Clash 常见端口）
      proxy = http://127.0.0.1:10809         （v2rayN 常见 HTTP 端口）
      proxy = socks5h://127.0.0.1:10808      （SOCKS5 代理）
  具体端口以你的代理软件里显示的为准。代理只用于访问币安；DeepSeek 直连。


七、配置文件 config.ini 一览
--------------------------------------------------------------------------------
  [deepseek]  api_key（必填）、model、base_url
  [binance]   api_key、api_secret（选填，同时填或同时空）、proxy（选填）
  [web]       port（默认 8866）、open_browser（启动后是否自动打开浏览器，yes / no）
  改完 config.ini 要重新运行 start.bat 才生效。
  ⛔ config.ini 里有你的密钥：不要发给别人、不要上传到网上（.gitignore 已经忽略了它）。


八、常见问题
--------------------------------------------------------------------------------
  Q：提示「自动下载 Python 失败」？
  A：一般是网络问题。程序会依次尝试 python.org 官方源和 npmmirror 国内镜像，下载后核对官方
     SHA256，对不上会拒绝使用。请确认能上网（需要代理的先开代理）后重新双击 start.bat。
     实在不行，也可以自己装 Python 3.12（https://www.python.org/downloads/windows/ ，
     安装时勾选 "Add python.exe to PATH"），start.bat 会自动用它。

  Q：提示「虚拟环境 .venv 已损坏」？
  A：不用管，start.bat 会自动删掉重建（常见原因是电脑上的 Python 被卸载或升级了）。

  Q：安装依赖失败？
  A：程序会依次尝试 官方 PyPI、阿里云、清华、中科大 四个源。全部失败一般是网络问题，
     平时上网需要代理的，请先打开代理再运行。也可以删除 .venv 文件夹后重新双击 start.bat。

  Q：提示端口 8866 被占用？
  A：可能已经开着一个 aiQuantHelper 窗口，先关掉；或把 config.ini 的 [web] port 改成 8877 等。

  Q：页面上某一块显示红色「出错：……」？
  A：每块数据独立查询，出错的那块会写明原因（如 -2015 = Key 无效或 IP 不在白名单）。
     也可以直接问 AI 助手「这个报错怎么处理」，它会查运维手册回答。
     完整的错误处理说明见 docs/runbook.md 。

  Q：AI 助手报 401 / 402？
  A：401 = DeepSeek key 不对；402 = DeepSeek 余额不足，到 platform.deepseek.com 充值。

  Q：能不能让 AI 帮我平仓 / 下单？
  A：不能。本程序刻意设计为只读，所有操作请在币安 App 或网页上手动完成。

  Q：别的电脑能访问这个页面吗？
  A：不能。服务只监听本机 127.0.0.1，这是有意的安全设计（页面上有你的账户数据）。

  Q：想改演示数据？
  A：mock/ 目录里的 JSON 就是币安接口的原始返回格式，用记事本改数字后刷新页面即可。


九、目录结构
--------------------------------------------------------------------------------
  start.bat               一键启动（准备 Python、建环境、装依赖、检查配置、启动服务）
  config.example.ini      配置模板（第一次运行时自动复制成 config.ini）
  requirements.txt        Python 依赖
  app\main.py             启动入口：检查配置 → 验证 DeepSeek key → 币安自检 → 启动网页服务
  app\config.py           读取与校验 config.ini
  app\binance.py          币安只读客户端（只有 GET 请求）
  app\datasource.py       数据层：实盘（币安）/ 演示（mock 文件）两种来源，同一套处理
  app\mcp_server.py       MCP Server：给 AI 用的 9 个只读工具
  app\agent.py            AI 运维 Agent：DeepSeek 大模型 + MCP 工具调用
  app\web.py              网页服务（只监听 127.0.0.1）
  app\static\index.html   页面（账户概览 + AI 运维助手对话框）
  app\runbook.py          运维手册检索（BM25）
  docs\runbook.md         运维手册：错误码、代理、风险概念等，可自行追加条目
  mock\                   演示模式的模拟数据
  tools\setup.ps1         start.bat 调用：准备 Python（没有就自动下载）、创建 / 修复 .venv
  tools\bootstrap.py      setup.ps1 调用：安装依赖（多源自动切换）、生成 config.ini
  .python\  .venv\        运行时自动生成：免安装 Python、虚拟环境（都可以随时删除，下次自动重建）
  tests\                  自动测试
  logs\                   运行日志（app.log）和 AI 问答审计（audit.jsonl，不记录密钥）


十、进阶用法（可选）
--------------------------------------------------------------------------------
  · 只做自检、不启动服务：   start.bat --check
  · 使用另一份配置文件：     start.bat --config D:\path\to\other.ini
  · 命令行直接问 AI：        .venv\Scripts\python -m app.agent "我的仓位是什么情况"
  · 运行自动测试：           .venv\Scripts\python -m pytest tests
    （不需要任何 key、不访问网络）
  · 接入其他 MCP 客户端：     命令 .venv\Scripts\python -m app.mcp_server ，
    并设置环境变量 AQH_CONFIG 指向你的 config.ini 。
