# aiQuantHelper 运维手册

AI 运维助手回答「为什么 / 怎么处理」类问题时会检索本手册，并引用条目编号（如 R5）。
你可以按同样的格式（`## R编号 标题`）往里加自己的条目，保存后下一次提问就会生效，不用重启。

## R1 本程序能做什么、不能做什么
aiQuantHelper 是币安 U 本位合约账户的只读运维助手：查看权益、持仓、挂单与条件单、资金流水（已实现盈亏、手续费、资金费）、现货余额，做风险体检，并通过 AI 对话解释账户状况。
它没有任何下单、撤单、改杠杆、划转、提现的功能，AI 也没有这类工具。需要操作时，请到币安 App 或网页手动处理。

## R2 演示模式（MOCK）与实盘模式（LIVE）怎么切换
config.ini 的 [binance] 下 api_key 和 api_secret 都留空 ⇒ 演示模式，数据来自 mock/ 目录，页面顶部显示黄色「MOCK 演示数据」。
两个都填 ⇒ 实盘模式，只读查询真实账户，页面顶部显示绿色「LIVE 实盘」。只填一个 ⇒ 程序拒绝启动。
改完 config.ini 后需要关闭窗口、重新运行 start.bat 才生效。

## R3 如何创建只读的币安 API Key
1. 登录币安网页版，右上角头像 → API 管理（API Management）→ 创建 API → 选「系统生成」(HMAC)。
2. 完成安全验证后得到 API Key 和 Secret Key。Secret Key 只显示一次，立即复制。
3. 编辑权限：只勾选「允许读取」(Enable Reading)。如果要看合约账户，币安要求账户已开通合约。不要勾选「允许现货及杠杆交易」「允许合约」「允许提现」。
4. 建议设置 IP 白名单（见 R4）。
5. 把 API Key 填进 config.ini 的 api_key，Secret Key 填进 api_secret。

## R4 IP 白名单
在币安 API 管理里可以给 Key 绑定 IP，绑定后只有这些 IP 能用这个 Key，安全性高很多。
如果你通过代理访问币安，币安看到的是代理出口的 IP，白名单要填出口 IP（不是本机内网 IP）。
出口 IP 变了（换代理节点、换网络）会导致 -2015 错误。

## R5 错误 -2015 / -2008 / -2014：API Key 无效或没有权限
-2008（Invalid Api-Key ID）、-2014（API-key format invalid）：api_key 填错了或已被删除，重新从币安复制。
-2015（Invalid API-key, IP, or permissions for action）有三种可能：① api_key 填错或已删除；② 当前出口 IP 不在白名单里（R4）；③ Key 没有对应权限，例如查合约需要账户已开通合约。
排查：在 AI 助手里问「检查一下币安连接和 API 权限」，或到币安 API 管理页面核对 Key 和白名单。

## R6 错误 -1022：Signature for this request is not valid
签名不对，几乎都是 api_secret 填错：多复制了空格、换行，或把 API Key 填进了 secret。重新从币安复制 Secret Key（如果已经看不到，只能删掉重建 Key）。

## R7 错误 -1021：Timestamp for this request is outside of the recvWindow
本机时间和币安服务器时间相差太大。程序会自动对时重试一次；如果仍然报错：Windows「设置 → 时间和语言 → 日期和时间」打开「自动设置时间」并点「立即同步」。

## R8 连不上币安 / HTTP 451 / 请求超时
部分地区和网络无法直连币安（表现为超时、连接被重置，或 HTTP 451 地区限制）。
处理：在 config.ini 的 [binance] proxy 填代理地址，例如 `http://127.0.0.1:7890`（Clash 常见端口）或 `http://127.0.0.1:10809`（v2rayN 常见 HTTP 端口）；SOCKS5 代理写 `socks5h://127.0.0.1:10808`。
代理只用于访问币安，DeepSeek 直连。代理不稳定时偶尔会超时，程序会自动重试 2 次。

## R9 HTTP 418 / 429：请求过于频繁
币安按 IP 限流。页面默认 30 秒刷新一次，正常使用不会触发。如果多开了很多页面或别的程序共用这个 IP，可能被限流，等 1~2 分钟自动恢复；418 表示被临时封禁，时间更长。

## R10 DeepSeek 报错 401 / 402 / 429
401：大模型 API Key 错误，检查 config.ini 的 [deepseek] api_key。402 Insufficient Balance：DeepSeek 账户余额不足，到 platform.deepseek.com 充值。429：请求太频繁，稍后再试。
启动时如果 401，程序会拒绝启动并提示。

## R11 强平价、保证金率是什么意思
强平价（liquidation price）：标记价格到达这个价位时仓位会被强制平仓。「强平距离」= 标记价离强平价还有百分之几，越小越危险，低于 10% 体检会报警，低于 5% 是危险。
保证金率 = 维持保证金 / 保证金余额（权益）。达到 100% 会触发强平。全仓模式下所有仓位共用保证金，一个仓位亏损会拉低其他仓位的强平距离。

## R12 资金费（Funding Fee）
永续合约每 8 小时（部分币种 4 小时或 1 小时）结算一次资金费：资金费率为正时多头付给空头，为负时空头付给多头。
资金费 = 持仓名义价值 × 资金费率。长期持有大仓位时，资金费可能是一笔不小的成本，可以在「资金流水」里按币种查看。

## R13 杠杆过高怎么处理
本工具的「杠杆」指总敞口 / 权益（实际杠杆），不是币安里给每个币设置的杠杆倍数。超过 3 倍会提示关注，超过 5 倍提示危险。
降低实际杠杆只有两种办法：减仓，或者往合约账户转入保证金。这些操作需要你在币安手动完成，AI 不会也不能替你执行。

## R14 止损单与条件单（Algo 订单）
币安新版把止损（STOP_MARKET）、止盈（TAKE_PROFIT_MARKET）等条件单放在 Algo 订单接口，普通挂单列表里看不到。本工具会同时查询两个接口，挂单表中「类别」列显示「条件单」的就是。
体检里「这些持仓没有挂止损条件单」是提醒，不是错误；是否设置止损由你的交易策略决定。

## R15 页面打不开 / 端口被占用
启动窗口里会打印页面地址（默认 http://127.0.0.1:8866/）。如果提示端口被占用，可能是已经开着一个 aiQuantHelper 窗口，先关掉它；或者把 config.ini 的 [web] port 改成别的数字（如 8877）。
页面只监听本机 127.0.0.1，同一局域网的其他电脑打不开，这是有意的安全设计。

## R16 修改演示（MOCK）数据
mock/ 目录里的 JSON 文件就是币安接口的原始返回格式：position_risk.json（持仓）、futures_account.json（账户）、open_orders.json（普通挂单）、open_algo_orders.json（条件单）、income.json（资金流水）、spot_account.json（现货）、premium_index.json（标记价与资金费率）。
可以用记事本修改其中的数字，刷新页面即生效。时间字段会被自动平移到「最近」，所以任何一天打开都能看到近 7 天的流水。

## R17 全仓与逐仓
全仓（cross）：账户里所有可用余额都是保证金，所有全仓仓位共担风险。逐仓（isolated）：每个仓位只用分配给它的保证金，亏完只强平这一个仓位。
持仓表的「保证金」列显示每个仓位的模式。

## R18 未实现盈亏与已实现盈亏
未实现盈亏：按当前标记价计算、还没平仓的浮动盈亏，会随价格变动。已实现盈亏：已经平仓锁定的盈亏，记在资金流水里（REALIZED_PNL）。
权益（保证金余额）= 钱包余额 + 未实现盈亏；手续费和资金费直接从钱包余额里扣。

## R19 API Key 的安全建议
只给读取权限、绑定 IP 白名单、不开提现权限。如果体检里的连接检查提示「这个 API Key 开启了提现权限」，请立即到币安关闭。
config.ini 里保存着你的 Key：不要把它发给任何人、不要上传到网上（.gitignore 已忽略 config.ini）。

## R20 可用余额为 0 或很低
可用余额 = 权益 − 仓位占用的初始保证金 − 挂单占用。可用余额为 0 表示已经没有余量：不能开新仓，价格继续不利时离强平更近。
处理思路：减仓、或往合约账户转入资金（需在币安手动操作）。
